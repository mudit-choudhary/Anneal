# Anneal application: runtime dependencies only.
#
# From the repository root:
#   python3.12 -m venv virtual_environments/annealenv
#   virtual_environments/annealenv/bin/pip install -r app/requirements.txt
#   virtual_environments/annealenv/bin/pip install --force-reinstall --no-deps onnxruntime-gpu==1.23.2
#
# The last line matters. chromadb hard-requires the CPU build of onnxruntime,
# and both builds install into the same `onnxruntime` package, so whichever
# lands last wins. Reinstalling the GPU build last keeps layout detection on the
# GPU; without it, it silently runs on the CPU (about 6x slower).
#
# Every package below is imported directly by code that `anneal` runs; nothing
# is listed only because another package needs it. Versions are the ones the
# round-2 evaluation ran on, with one exception: that environment paired
# arxiv 2.1.0 (which hard-pins requests==2.31.0) with requests 2.34.2, a
# combination pip will not install. arxiv 2.4.1 keeps the same API and allows a
# requests release with the 2024 security fixes. Neither affects the evaluation,
# which builds its corpus with requests and feedparser directly.
